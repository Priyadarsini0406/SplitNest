# SplitNest Backend

Backend REST API for the SplitNest application.

## Technology

- Node.js
- Express.js
- MongoDB
- Mongoose

## Run Project

Install dependencies:

npm install

Development:

npm run dev

Server:

http://localhost:5000

## Property APIs

GET /api/properties

GET /api/properties/:id

POST /api/properties

PUT /api/properties/:id

PATCH /api/properties/:id/status

DELETE /api/properties/:id
